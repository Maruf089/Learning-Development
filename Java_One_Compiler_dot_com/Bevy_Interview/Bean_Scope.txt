

scope in Spring boot is used to Define behavior of the bean. this can be set with the help of @scope annotation in Spring boot. there are two main Scopes:
- singleton which is the default scope and tells that only one instance of The Bean will be created during the complete life cycle 
- second one is prototype which tells that a new instance will be created every time you will invoke getBean() method or Autowired the bean

besides this there are additional Scopes:
which are related to the web application
- request scope which will create a new instance for every HTTP request 
- session which will create a new instance for every HTTP session 
- Global session which is same as session only but related to the HTTP Global session 
- application which is same as singleton only but related to the web application context
