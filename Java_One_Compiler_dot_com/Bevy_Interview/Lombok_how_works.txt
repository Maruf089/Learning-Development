- Lombok :
Lombok is a popular Java library that helps reduce boilerplate code by generating common methods like getters, setters, constructors, and more through annotations. It allows developers to write cleaner and more concise code by automating the generation of repetitive code patterns. 

How Lombok works:
Lombok uses annotations to indicate which methods or constructors should be generated for a class. When you compile your code, Lombok processes these annotations ( by extending JSR annotation processor ), modify Abstract Syntax Tree(AST). Finally, the modified AST is converted back into bytecode, which is then compiled into class files that can be executed by the Java Virtual Machine (JVM). There will be no lombok code in the final bytecode; only the generated methods will be present.

For example, if you annotate a class with @Getter and @Setter, Lombok will generate the getter and setter methods for all the fields in that class during compilation.

- Sealed Classes : Sealed classes are basically used to restrict which other classes or interfaces can extend or implement them. So basically, when you create a sealed class, you have to specify the permitted subclasses that can extend that particular sealed class. This is mainly used for better control over the class hierarchy and to enhance security by preventing unauthorized subclassing.

- Records : Records are a special kind of class in Java that is used to model immutable data. When you create a record, the compiler automatically generates boilerplate code for you, such as constructors, getters, equals(), hashCode(), and toString() methods. This makes it easier to create classes that primarily hold data without having to write a lot of repetitive code.
